# Капитал

Учёт доходов и расходов в виде игры. Каждый источник дохода — отдельная яркая карта, доход за 7 дней определяет твой уровень: от «Нищего» до «Бизнесмена».

**Открыть:** https://najibsolkhua-cmd.github.io/my/

## Что умеет

- **Карты доходов.** Работа, подработка, проект, бизнес. У каждой свой цвет, узор и иконка. Внутри: история по дням, месяцам и годам, часы работы и заработок в час.
- **Таймер работы.** Нажми «Начать работу», после «Стоп» время подставится в запись дохода само.
- **Расходы.** 22 готовые категории с иконками (рестораны, дом, авто…) и свои категории: выбираешь иконку, цвет и название.
- **На счету.** Всегда видно, сколько денег сейчас: стартовый капитал (сумма до начала учёта) + все доходы − все расходы. Доход и расход — за выбранную неделю, месяц или год, с графиком.
- **Долги.** Запиши, сколько и за что должен; расходы с пометкой «В счёт долга» списывают его. Награды — только за погашение, «Свободный человек» — когда закрыты все долги.
- **Уровни** по доходу за последние 7 дней:

  | Уровень | Доход за 7 дней |
  |---|---|
  | Нищий | до 5 000 ₽ |
  | Охотник за монетками | от 5 000 ₽ |

  | Ударник труда | от 15 000 ₽ |
  | Офисный планктон | от 20 000 ₽ |
  | Менеджер | от 30 000 ₽ |
  | Мастер дедлайнов | от 40 000 ₽ |
  | Стартапер | от 50 000 ₽ |
  | Денежный мешок | от 75 000 ₽ |
  | Предприниматель | от 100 000 ₽ |

  | Магнат | от 500 000 ₽ |
  | Титан | от 750 000 ₽ |
  | Бизнесмен | от 1 000 000 ₽ |

- **Цели** (доход за неделю или месяц, накопить сумму), **76 наград** (6 из них секретные) и **серия дней** подряд. Полный список — в [справочнике](docs/kapital-wiki.pdf).
- Работает **без интернета**, ставится на главный экран телефона, данные хранятся только на устройстве. Есть резервная копия в файл.

## Установка на телефон

- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран Домой».
- **Android:** открыть в Chrome → меню ⋮ → «Добавить на главный экран».

## Приложение для iPhone

Полноценное приложение: работает без интернета, таймер смены идёт на экране блокировки и в Dynamic Island, даже когда приложение закрыто. Уведомления настраиваются в приложении (шестерёнка → «Уведомления»).

**Скачать:** https://github.com/najibsolkhua-cmd/my/releases/download/ios/Kapital.ipa

Установка с бесплатным Apple ID через компьютер:

1. Установи на компьютер [Sideloadly](https://sideloadly.io). На Windows ещё нужны iTunes и iCloud с сайта Apple (не из Microsoft Store).
2. Подключи iPhone кабелем и нажми на телефоне «Доверять».
3. Перетащи `Kapital.ipa` в Sideloadly, введи свой Apple ID и нажми Start.
4. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
5. На iOS 16 и новее: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, телефон перезагрузится.

С бесплатным Apple ID подпись действует 7 дней. Потом приложение нужно переустановить через Sideloadly (данные сохраняются) или включить в Sideloadly автообновление. С платным аккаунтом Apple Developer ($99 в год) можно ставить через TestFlight без компьютера.

## Android-приложение (APK)

APK собирается автоматически при каждом изменении в `main` и выкладывается в [Releases](https://github.com/najibsolkhua-cmd/my/releases).

**Скачать:** https://github.com/najibsolkhua-cmd/my/releases/download/apk/Kapital.apk

Подпись APK вычисляется из секрета `SIGNING_SEED` (Settings → Secrets and variables → Actions). Пока фраза та же, новая версия ставится поверх старой и данные сохраняются. Если фразу потерять или поменять, придётся удалить приложение и поставить заново, поэтому перед этим сохрани резервную копию.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты логики
npm run build    # сборка в dist/
npx cap sync android   # скопировать сборку в Android-проект (нужен Android Studio)
```

React 19 + TypeScript + Vite, состояние в zustand с сохранением в localStorage. При пуше в `main` GitHub Actions прогоняет тесты и публикует приложение на GitHub Pages.
