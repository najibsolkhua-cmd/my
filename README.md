# Капитал

Учёт доходов и расходов в виде игры. Каждый источник дохода — отдельная яркая карта, доход за 7 дней определяет твой уровень: от «Нищего» до «Бизнесмена».

**Открыть:** https://najibsolkhua-cmd.github.io/my/

## Что умеет

- **Карты доходов.** Работа, подработка, проект, бизнес. У каждой свой цвет, узор и иконка. Внутри: история по дням, месяцам и годам, часы работы и заработок в час.
- **Смена с таймером.** Нажми «Начать смену», после «Стоп» время подставится в запись дохода само.
- **Расходы.** 22 готовые категории с иконками (рестораны, дом, авто…) и свои категории: выбираешь иконку, цвет и название.
- **Главное табло.** Доход, расход и остаток в рублях за неделю, месяц, год или всё время, график и последние операции.
- **Уровни** по доходу за последние 7 дней:

  | Уровень | Доход за 7 дней |
  |---|---|
  | Нищий | до 10 000 ₽ |
  | Работяга | от 10 000 ₽ |
  | Офисный планктон | от 20 000 ₽ |
  | Менеджер | от 30 000 ₽ |
  | Топ-менеджер | от 40 000 ₽ |
  | Малый предприниматель | от 50 000 ₽ |
  | Предприниматель | от 100 000 ₽ |
  | Инвестор | от 250 000 ₽ |
  | Магнат | от 500 000 ₽ |
  | Бизнесмен | от 1 000 000 ₽ |

- **Цели** (доход за неделю или месяц, накопить сумму), **награды** и **серия дней** подряд.
- Работает **без интернета**, ставится на главный экран телефона, данные хранятся только на устройстве. Есть резервная копия в файл.

## Установка на телефон

- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран Домой».
- **Android:** открыть в Chrome → меню ⋮ → «Добавить на главный экран».

## Android-приложение (APK)

APK собирается автоматически при каждом изменении в `main` и выкладывается в [Releases](https://github.com/najibsolkhua-cmd/my/releases).

**Скачать:** https://github.com/najibsolkhua-cmd/my/releases/download/apk/Kapital.apk

Подпись APK вычисляется из секрета `SIGNING_SEED` (Settings → Secrets and variables → Actions). Пока фраза та же, новая версия ставится поверх старой и данные сохраняются. Если фразу потерять или поменять, придётся удалить приложение и поставить заново, поэтому перед этим сохрани резервную копию.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты логики
npm run build    # сборка в dist/
npx cap sync android   # скопировать сборку в Android-проект (нужен Android Studio)
```

React 19 + TypeScript + Vite, состояние в zustand с сохранением в localStorage. При пуше в `main` GitHub Actions прогоняет тесты и публикует приложение на GitHub Pages.
